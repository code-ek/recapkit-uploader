Privacy policy

Last updated: 13 October 2026

recapkit uploader ("the app") is a private tool run by the owner of the Twentyfifth Recaps YouTube channel to publish that owner's own videos. This policy explains what Google user data the app uses and how.

Data the app accesses

When the channel owner signs in with Google, the app requests access to YouTube (https://www.googleapis.com/auth/youtube) and uses it only to:

  • identify which YouTube channel the signed-in account manages, so uploads go to the right channel;
  • upload the owner's videos and set their title, description, tags, visibility and publish time;
  • read the processing and visibility status of videos the app uploaded;
  • delete a video when the owner explicitly asks.

The app does not read comments, subscribers, viewing history, email, contacts or any other Google data.

How data is stored

The sign-in token Google issues is stored only on the owner's own computer, in a folder that only the owner's user accounts can open. Video details are kept in local files on that computer. No data is sent to any server run by the app; the only network traffic is to Google's own APIs.

Sharing

Google user data is never sold, shared with third parties, used for advertising, or used to train AI or machine-learning models. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is covered by the Google Privacy Policy.

Removing access and deleting data

You can revoke the app's access at any time at Google Account permissions or through Google security settings. Revoking access makes the stored token useless; the owner can also delete the token file from their computer. To ask a question or request deletion, email 20tyfifth@gmail.com.

Changes

If the app's use of data changes, this page will be updated and the date above changed.
